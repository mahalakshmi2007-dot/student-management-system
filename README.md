# Student Management System 🎓

A responsive Student Registration and Management Application built using React.js.

## Features
- Student registration
- View student details
- Search students
- Edit student information
- Delete student records
- Form validation
- Responsive user interface

## Technologies Used
- React.js
- JavaScript
- HTML
- CSS
- Vite

## Run Locally

```bash
npm install
npm run dev
```
